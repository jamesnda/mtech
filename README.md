# M-TECH School

M-TECH School is a beginner-friendly learning platform for mathematics, web development, and data analysis. Lessons connect core ideas to real-world applications and finish with a practical project.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The app uses plain HTML, CSS, and vanilla JavaScript; no build step or package installation is required.

## Learning experience

- Explore three beginner tracks with three modules each.
- Open a module to read a worked example, visit an external real-world resource, and review its project brief.
- Save module completion and project plans in the current browser using local storage.
- Use the responsive dashboard, track pages, project studio, and topic search to find the next step.
